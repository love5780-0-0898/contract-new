# 市场基准对比表

基于 claude-legal-skill 的市场标准，适配中国合同法律环境。

## 一、核心条款市场基准

| 条款 | 市场标准 | 黄旗警示 | 红旗警示 |
|------|----------|----------|----------|
| **违约金上限** | 合同总价款12个月费用 | 6-11个月 | <6个月 |
| **竞业限制期限** | 1-2年 | 3-4年 | 5年以上 |
| **竞业限制地域** | 业务实际经营区域 | 省级范围 | 全国范围 |
| **自动续约通知期** | 90天以上 | 60-89天 | <60天 |
| **解除通知期** | 双方对等，60-90天 | 单方30天 | 即时解除 |
| **赔偿条款** | 双向，有上限 | 不对等 | 无上限 |
| **陈述保证存续期（M&A）** | 12-18个月（一般） | 24-30个月 | 36个月以上 |
| **托管金（M&A）** | 10-15%，12-18个月 | 15-20%，18-24个月 | >20%或>24个月 |
| **保密期限（NDA）** | 3年（一般信息） | 2年 | 5年以上 |
| **中介费尾期** | 12-18个月 | 24个月 | 永久 |
| **SLA可用性** | 99.9%+赔偿机制 | 99.5% | 无SLA |
| **数据导出权** | 90天，标准格式 | 30天 | 无 |
| **涨价上限** | CPI或年5% | 年10% | 无上限 |
| **整改期** | 30天 | 15天 | 无 |

## 二、CSDN特定标准（结合审核要点）

### CSDN为甲方时

| 条款 | CSDN标准 | 可接受范围 | 红线 |
|------|----------|-----------|------|
| **逾期付款违约金** | 万分之三/日 | 万分之三~万分之五 | >万分之五 |
| **违约金累计上限** | 逾期金额10% | 10%-15% | 无上限 |
| **验收整改期** | 3个工作日 | 3-7个工作日 | >7天或无整改期 |
| **管辖法院** | 甲方所在地 | 协商或原告所在地 | 乙方所在地 |
| **保密期限** | 3年 | 2-3年 | <2年或永久 |
| **保密违约金** | 合同总价款10% | 5%-10% | 无违约金 |
| **质量违约金** | 合同总价款10% | 5%-15% | 无违约金 |
| **知识产权归属** | 归甲方 | 约定明确 | 归乙方或约定不明 |

### CSDN为乙方时

| 条款 | CSDN标准 | 可接受范围 | 红线 |
|------|----------|-----------|------|
| **逾期付款违约金** | 千分之五/日 | 千分之三~千分之五 | <千分之三 |
| **逾期付款解除权** | 逾期15日可解除 | 15-30日 | 无解除权 |
| **违约金累计上限** | 合同总价款30% | 20%-30% | >30%或无上限 |
| **验收期限** | 3个工作日内验收 | 3-7个工作日 | >7天或无限期 |
| **管辖法院** | 乙方所在地 | 协商或原告所在地 | 甲方所在地 |
| **保密期限** | 2年 | 1-2年 | >3年或永久 |
| **知识产权归属** | 未约定的归乙方 | 约定明确 | 全部归甲方 |

## 三、常见条款Redline建议模板

### 1. 违约金过高（CSDN为甲方）

**原文：** "甲方逾期付款按日万分之五支付违约金"
**Redline：** "甲方逾期付款按日**万分之三**支付违约金，**累计不超过逾期金额的10%**"
**依据：** 审核要点§二(一)甲方视角：逾期付款违约金每逾期一日按逾期金额的万分之三计算，累计不超过逾期金额的10%
**可谈判性：** 高 — 大多数供应商接受万分之三标准

### 2. 管辖不利于CSDN（CSDN为甲方）

**原文：** "任何一方均有权向乙方所在地人民法院提起诉讼"
**Redline：** "任何一方均有权向**甲方所在地**人民法院提起诉讼"
**依据：** 审核要点§七(一)甲方视角：优先方案为诉讼加甲方所在地管辖
**可谈判性：** 中 — 取决于双方议价能力

### 3. 缺少违约金上限（CSDN为乙方）

**原文：** "乙方违约应赔偿甲方全部损失"
**Redline：** "乙方违约应赔偿甲方损失，**但违约金累计金额不得超过合同总价款的30%**"
**依据：** 审核要点§四(二)乙方视角：违约金累计不超过合同总价款30%
**可谈判性：** 高 — 合理的上限条款通常可接受

### 4. 缺少保密违约金

**原文：** "双方应对商业秘密保密"
**Redline：** "双方应对商业秘密保密，**保密期限为合同终止后[X]年，违反保密义务应支付合同总价款10%的违约金**"
**依据：** 审核要点§七：保密违约金为合同总价款10%
**可谈判性：** 高 — 标准条款

### 5. 缺少知识产权归属

**原文：** （无相关条款）
**Redline：** "**乙方基于本合同提供的设计方案、软件等成果，知识产权归甲方所有，乙方不得擅自使用、转让。乙方保证所提供的标的、技术资料等不侵犯任何第三方的知识产权。**"
**依据：** 审核要点§六(一)甲方视角：乙方保证所提供的标的不侵犯第三方知识产权，成果归甲方
**可谈判性：** 中 — 取决于合同性质

## 四、可谈判性评级

| 评级 | 含义 | 示例 |
|------|------|------|
| **高** | 通常可接受 | 双向解除权、整改期、数据导出 |
| **中** | 取决于议价能力 | 违约金比例、价格上限、管辖 |
| **低** | 很少能改 | 支付网络规则、监管要求 |
| **无** | 不可谈判 | 银行监管规定、法定要求 |

---

## 五、议价能力因素

- **大客户 + 小供应商** = 更高议价能力
- **创业公司 + 大企业供应商** = 更低议价能力
- **竞争性市场** = 更高议价能力
- **独家供应商** = 更低议价能力
- **监管条款** = 无议价能力（法定要求）
