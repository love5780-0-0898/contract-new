# 合同类型定义及审核清单

## 一、合同类型分类

### 1. 采购合同
**特征：** CSDN 作为甲方（买方），向供应商采购商品或服务
**常见标的：** IT设备、网络服务、办公用品、工程建设、健康管理服务
**关键字段：** 标的物描述、数量、单价、总价（含税）、交付时间、验收标准
**CSDN 角色：** 甲方

**审核重点：**
- [ ] 价款是否含税、包含一切费用
- [ ] 验收合格后付款、先票后款
- [ ] 逾期付款违约金 ≤ 万分之三/日，上限10%
- [ ] 乙方质量违约：退全款 + 10%违约金 + 全额赔偿
- [ ] 管辖：甲方所在地法院
- [ ] 成果知识产权归甲方
- [ ] 保密期限3年

### 2. 销售合同 / 技术服务合同
**特征：** CSDN 作为乙方（卖方/服务方），向客户提供技术服务或产品
**常见标的：** 技术服务、平台开发、广告推广、培训服务、赞助合作
**关键字段：** 服务内容、服务期限、服务费用、验收标准、交付物
**CSDN 角色：** 乙方

**审核重点：**
- [ ] 标的交付后付款、先款后票
- [ ] 逾期付款违约金 ≥ 千分之五/日
- [ ] 逾期超过15日有权单方解除
- [ ] 违约金上限：合同总价款30%
- [ ] 管辖：乙方所在地法院
- [ ] 未约定归属的成果知识产权归乙方
- [ ] 保密期限2年

### 3. 合作协议
**特征：** 双方合作经营、联合推广等
**常见标的：** 联合运营、渠道合作、品牌合作
**关键字段：** 合作模式、收入分配、双方职责、合作期限
**CSDN 角色：** 视具体条款而定

**审核重点：**
- [ ] 收入分配是否公平合理
- [ ] 费用承担是否明确
- [ ] 各方职责是否对等
- [ ] 知识产权归属
- [ ] 客户投诉处理责任划分
- [ ] 违约责任是否对等

### 4. 代销合同
**特征：** CSDN 代销他人商品或委托他人代销 CSDN 商品
**常见标的：** 商品代销、委托销售
**关键字段：** 代销商品明细、结算价、销售价、结算周期
**CSDN 角色：** 通常为代销方（甲方）

**审核重点：**
- [ ] 代销商品明细是否完整
- [ ] 结算价和销售价是否明确
- [ ] 结算周期和对账流程
- [ ] 商品验收标准
- [ ] 售后责任划分
- [ ] 未售商品处理方式
- [ ] 运费承担

### 5. 保密协议 / NDA
**特征：** 单独的保密协议
**CSDN 角色：** 视情况而定

**审核重点：**
- [ ] 保密范围是否明确
- [ ] 保密期限是否合理
- [ ] 违约金标准
- [ ] 除外条款（已公开信息、合法获取信息）

### 6. 赞助协议
**特征：** CSDN 赞助活动或被赞助
**常见标的：** 大会赞助、活动赞助
**CSDN 角色：** 赞助方或被赞助方

**审核重点：**
- [ ] 赞助费用及支付方式
- [ ] 赞助权益是否明确
- [ ] 知识产权使用许可
- [ ] 活动取消或变更处理
- [ ] 违约责任

### 7. 补充协议
**特征：** 对主合同的修改或补充
**CSDN 角色：** 与主合同一致

**审核重点：**
- [ ] 补充协议与主合同关系
- [ ] 冲突条款处理
- [ ] 是否有不利于主合同的变更

## 二、合同类型识别关键词

| 合同类型 | 关键词 |
|----------|--------|
| 采购合同 | 采购、购买、购销、订购、供货、送货 |
| 销售/服务合同 | 销售、技术服务、开发服务、平台服务、推广 |
| 合作协议 | 合作、联合、共同、协作、代理 |
| 代销合同 | 代销、委托销售、代理销售、经销 |
| 保密协议 | 保密、NDA、不披露 |
| 赞助协议 | 赞助、冠名、合作推广 |
| 培训协议 | 培训、教育、课程 |
| 补充协议 | 补充、变更、修改、调整 |

## 三、CSDN 角色识别规则

### CSDN 为甲方的信号：
- CSDN/创新乐知/涛伯开源出现在"甲方"位置
- 合同为采购性质（CSDN 买/付款方）
- 合同标题含"采购"、"购买"

### CSDN 为乙方的信号：
- CSDN/创新乐知/涛伯开源出现在"乙方"位置
- 合同为销售/服务性质（CSDN 卖/收款方）
- 合同标题含"销售"、"技术服务"、"服务协议"
